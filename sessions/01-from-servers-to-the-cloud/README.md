# Session 1: From servers to the cloud
Compute, network, storage, and how they moved

**Date:** 2026-11-16, 16:30–19:00

## Goals
By the end of this session you can:
- Explain what makes something cloud computing, and tell IaaS, PaaS and SaaS apart.
- Choose between virtual machines, containers and serverless, and name the Google Cloud and AWS service for each kind of storage.
- Give someone access with IAM, using the least privilege that works.
- Create infrastructure with Terraform (`init`, `plan`, `apply`) and explain why its state stays out of git.
- Describe how code reaches production: branch, pull request, then dev, test and production.

You leave with your own Google Cloud project, a budget alert, and a bucket created with Terraform that your neighbour can view.
