# Session 7: Dataflow
**Date:** 2026-12-02, 16:30–19:00

## Goals
By the end of this session you can:
- Build the streaming pipeline from Kafka and Pub/Sub into BigQuery. It is both the speed layer of your Lambda version and the single path of your Kappa version.
- Explain a pipeline as a graph of transforms, and test its logic without running it.
- Tell event time from processing time, and window events by the time they happened.
- Explain what a watermark is, and why a windowed count arrives later than the events in it.
- Run a streaming job on Dataflow, and drain it so it stops billing.
