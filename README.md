# Cloud Computing and Data Architectures — SRH Hamburg, Winter 2026

Over five weeks you build a freight-analytics data platform on Google Cloud, layer by layer, then redesign it and defend it at an architecture board.

Sessions run 16:30–19:00 in seminar room 1.4.

## Start here
1. Read the [course overview](COURSE_OVERVIEW.md)
2. [Set up Google Cloud](setup/gcp.md)
3. [Set up Databricks Free Edition](setup/databricks.md)
4. Fork this repo into your team's repo once teams form in session 4.
