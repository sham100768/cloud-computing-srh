# Session 2: Storing data in the cloud
Object storage, file formats and BigQuery

**Date:** 2026-11-18, 16:30–19:00

## Goals
By the end of this session you can:
- Explain how object storage works, and pick a storage class and lifecycle rule by how often the data is read.
- Compare CSV, JSON, Avro and Parquet, and explain why column storage suits analytics and row storage suits applications.
- Tell a data lake, a warehouse and a lakehouse apart.
- Explain how BigQuery separates storage from compute, and what you pay for when you query.
- Cut the bytes a query scans with partitioning and clustering, and check it with a dry run.

You leave with a month of freight data loaded into BigQuery and three business questions answered in SQL.
