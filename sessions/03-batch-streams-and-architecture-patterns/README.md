# Session 3: Batch, streams and architecture patterns
Lambda, Kappa, and the platform you'll build

**Date:** 2026-11-20, 16:30–19:00

## Goals
By the end of this session you can:
- Tell batch from stream processing, and choose freshness by what the user needs.
- Explain event time versus processing time, and why late data makes streaming hard.
- Describe the Lambda and Kappa architectures, and when each fits.
- Read the reference platform as a Lambda architecture.
- Record a design decision in an architecture decision record.

You leave with your own architecture diagram, ADR 001 and a batch delay-per-lane metric, in your fork of the course repo.
